# 知识关系与画像可视化

1. library.js：原生 SVG 分组节点图；搜索定位、选中节点显示直接关系、线型区分条件先修与关联、关系点击显示原始适用条件、侧栏显示个人证据。只使用目录中的关系，分组仅作视觉导航。
2. profiles.js/ui.js：画像概览、分组紧凑卡片、证据状态筛选、原生 dialog 侧边详情；保留综合评价到逐条观察到原始作答的追溯。无概率或总掌握等级。
3. style.css：蓝白设计，类别用蓝/紫/青/金，节点焦点、卡片悬停和键盘焦点，窄屏滚动画布及全宽抽屉。README 更新页面说明。
4. 定向 Node/Python 测试、浏览器真实保存数据只读检查关系选择/搜索、画像筛选/抽屉/证据、学生切换、空数据、桌面和手机截图。禁用测试写入，不调用模型或 Java。
