# 上下文操作入口与加载优化

1. 排查并记录现有 artifact 每次全量扫描的基线。增加缓存测试：一次索引后重复读取不扫描、文件变化重建、刷新发现新文件、删除/路径校验仍生效；前端并发请求去重、失败重试与刷新失效。
2. ArtifactStore 保存原子索引快照（白名单、解析数据、文件签名），只在 bootstrap 刷新或文件变化时重建。前端缓存 Promise，刷新清空后旧请求不回填。保持读取无副作用。
3. 在推荐记录、推荐详情、题目详情、画像页提供上下文操作入口，带入当前学生/画像/推荐/题目；任务中心展示全部会话任务并可选中查看。已有服务保留预览确认执行，未提供 operation 元数据时显示暂未接入并禁用执行。录入后更新带入接收任务，仍需选择基线画像与确认。
4. 针对性 Python/Node 测试及浏览器：冷启动、首次切学生、重复切换计时；快捷入口参数、任务列表、未接入状态、刷新恢复。写入用拦截假响应，不调用模型、不执行 Java。更新 README。
